# G0 科学基础验收报告 — Quasi Atlas

日期：2026-10-23

## 本次真正完成
- 精确定义了五个已审阅预设的 `Model/1.0`（坐标、有限域、单位、采样分辨率、float32）；
- `Experiment/1.0` 把数学内容、算法身份、E1 计算观察、备注打成可审计的实验包；
- 对科学内容执行 canonical JSON + SHA-256 完整性哈希；时间戳不进入哈希，复现实验内容跨时间相同；
- 非法输入、非有限数字、超大采样、未知模型、错误组件计数、修改后 hash 都拒绝；
- 严格限制 E2、E3、E4：**目前没有独立认证和数学证明实现，不允许通过前端数据任意升级等级。**
- 12 组已知解析形状 golden fixtures（B01–B12），外加常值退化场和临界点校验；
- GitHub Actions CI 模板：每次 PR/push 测试及静态站点构建；
- 正式站点是匿名、local-first 数学探索器；Neon/AWS/Cloudflare token 不参与前端 bundle 构建。

## 范围和已知限制
- 测试了等值线几何的**有限窗口**连通分量，尚未完成持久同调 H0/H1、数值拓扑严格认证与区间算术；
- SHA-256 可检查意外/事后修改，**不能提供身份签名或证明实验是真实产生的**：任何人仍可生成新哈希；
- `float32` 栅格，插值依然可能误判退化临界附近的拓扑；
- 常值场 `f=c` 的等值集是二维集合，Marching Squares 若返回零条折线并不代表数学等值集空；
- 跨浏览器 SVG/Canvas 像素不保证 bit-identical；
- 演示状态 JSON 与科研实验包分离；后者才持有验证过的模型和哈希；
- G0 完成数学结构初版和解析几何基准；后续严格独立 solver 的差异验证、框架长期复现基线属于 G1/G2/G3 的后续任务，不应夸大。

## 发布/安全
- 本项目不需要任何数据库写入或账号登录，故不创建 Neon schema。
- 部署时排除所有 `.env*`、local test 目录和研究材料；不向 Vite 注入服务端密钥。
- 不自动公开或复制 `.env` 到 Vercel 项目配置。
- 生产验收包含：JS 资源加载、五个地图、研究动作、E1 标识、浏览器无异常。
